Cara Mendapatkan Gemini API Key Gratis

Hanya butuh akun Google (Gmail) & waktu 1 menit

  1. Buka situs resmi Google AI Studio (aistudio.google.com) .
  2. Login menggunakan akun Google / Gmail Anda.
  3. Klik tombol biru "Create API key" (Buat kunci API).
  4. Pilih project yang tersedia (atau buat baru) lalu salin kode yang diawali huruf AIzaSy....
  5. Tempel kode tersebut ke kolom Google Gemini API Key di aplikasi ini dan klik Simpan Key.
